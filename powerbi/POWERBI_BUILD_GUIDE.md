# Power BI Build Guide

> **Why this file exists:** a `.pbix` is a proprietary binary format that only
> Power BI Desktop can write. It can't be generated by a script. This guide,
> combined with `DAX/measures.dax`, `DAX/calculated_columns.dax`, and
> `PowerQuery/power_query_m.pq`, lets you assemble the real `.pbix` in
> Power BI Desktop in well under an hour — every query, relationship, and
> measure is already written for you; you are wiring, not designing.

## 0. Prerequisites
- Power BI Desktop (latest, Windows 11)
- Repo cloned locally, e.g. `C:\Projects\Enterprise-Sales-Finance-Analytics-Dashboard\`
- Run the Python pipeline first so `data/processed/` is populated:
  ```powershell
  cd C:\Projects\Enterprise-Sales-Finance-Analytics-Dashboard\python
  pip install -r ..\requirements.txt
  python generate_sample_data.py
  python clean_data.py
  python build_kpis.py
  ```

## 1. Create the parameter and load tables
1. Open Power BI Desktop → **Get Data → Blank Query**.
2. **Home → Manage Parameters → New Parameter**: name `FolderPath`, type Text,
   current value `C:\Projects\Enterprise-Sales-Finance-Analytics-Dashboard\data\processed\`.
3. For each table (`DimDate`, `DimCustomer`, `DimProduct`, `DimRegion`,
   `DimInventory`, `FactSales`): create a Blank Query, open the **Advanced
   Editor**, paste the matching block from `PowerQuery/power_query_m.pq`,
   rename the query to the table name, click **Close & Apply**.

## 2. Build the model (Model view)
Create these relationships (all Many-to-One, single direction unless noted):

| From | To | Cardinality |
|---|---|---|
| FactSales[date_id] | DimDate[date_id] | Many-to-1 |
| FactSales[customer_id] | DimCustomer[customer_id] | Many-to-1 |
| FactSales[product_id] | DimProduct[product_id] | Many-to-1 |
| DimCustomer[region_id] | DimRegion[region_id] | Many-to-1 |
| DimInventory[product_id] | DimProduct[product_id] | Many-to-1 |
| DimCustomer[signup_date] | DimDate[full_date] | Many-to-1, **mark Inactive** (used by `New Customers` via `USERELATIONSHIP`) |

Mark **DimDate** as a Date Table: select the table → **Table tools → Mark as
Date Table** → column `full_date`.

## 3. Add DAX
- Select the **FactSales** table → **Modeling → New Measure** → paste each
  measure from `DAX/measures.dax` one at a time (each `MeasureName = ...`
  block is one measure).
- Add calculated columns from `DAX/calculated_columns.dax` on the tables
  indicated by the comments (`Modeling → New Column`).
- Organize measures into a display folder: select all measures → Properties
  pane → **Display folder** → `_KPI Measures`.

## 4. Theme
- **View → Themes → Browse for themes** → import `docs/theme.json`
  (provided in this repo) for the corporate navy/teal palette used in the
  screenshots.

## 5. Pages & layout
Create six pages (**Insert → New Page**), named exactly:

1. **Executive Dashboard** — KPI cards (Total Revenue, Total Profit, Profit
   Margin %, Total Orders, Total Customers), a Revenue vs Profit line chart
   by month, a region map, and a Top 5 Products bar chart.
2. **Sales Analytics** — Sales trend line chart with a trend line, Average
   Order Value card, Sales by Category treemap, matrix of Region × Category
   revenue.
3. **Financial Analytics** — Profit & Margin trend, Margin Status table
   (conditional formatting driven by `Margin Status` measure), cost vs
   revenue waterfall.
4. **Customer Analytics** — Customer Growth line chart (`New Customers`,
   cumulative), Customer Tier donut, Top 10 Customers table, Repeat Customer
   Rate card.
5. **Inventory Analytics** — Stock vs Reorder Level bar chart, Inventory
   Turnover Ratio table, Products Needing Reorder card, warehouse slicer.
6. **Forecast Dashboard** — Revenue line chart with **Analytics pane →
   Forecast** enabled (right-click the chart → Analytics → Forecast, set
   confidence interval to 95%, forecast length 6 periods), plus the
   `Linear Trend Revenue` and `Revenue 3M Moving Avg` measures as comparison
   lines.

## 6. Interactivity
- **Slicers**: Year (DimDate), Region (DimRegion), Category (DimProduct),
  Segment (DimCustomer) — placed in a slicer panel synced across pages
  (**View → Sync Slicers**).
- **Navigation buttons**: Insert → Buttons → Blank, one per page, with
  **Action → Type: Page Navigation** set to each dashboard page; group them
  in a top nav bar duplicated across all six pages.
- **Bookmarks**: create a bookmark per slicer preset (e.g. "This Year",
  "Last Year", "All Regions") via **View → Bookmarks → Add**, and wire
  buttons to them with **Action → Type: Bookmark**.
- **Drill-through**: create a page named `Product Drillthrough`, add a
  `product_id` field to the **Drillthrough** filter well, right-click any
  product bar on Sales Analytics → Drill through.
- **Tooltips**: create a tooltip page (`Page size → Tooltip` in page
  formatting) showing Revenue/Profit/Margin mini KPIs; set it as the
  **Tooltip** on the main charts via visual formatting → Tooltip → Report
  page.

## 7. Save
Save as `powerbi/Enterprise_Sales_Finance_Dashboard.pbix`. Add this file to
Git with **Git LFS** (binary, can grow large) — see `.gitattributes` in the
repo root.
